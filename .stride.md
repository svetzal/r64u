# Stride Configuration

**Note:** This project uses CMake and Qt 6 for building. The `stride` Claude Code
plugin runs these sections automatically around the matching Stride API calls, so
every command here must be safe to run unattended. Build parallelism is capped at
four jobs on purpose: the generator is Unix Makefiles, and an uncapped build
exhausts memory on a full rebuild.

## before_doing

Executes before starting work on a task (blocking, 60s timeout).

```bash
echo "Starting task $TASK_IDENTIFIER: $TASK_TITLE"
git pull --rebase origin main
cmake -B build -S . -DCMAKE_PREFIX_PATH=$HOME/Qt/6.11.2/macos -DCMAKE_BUILD_TYPE=Debug
```

## after_doing

Executes after completing work (blocking, 120s timeout).
If this fails, task completion should fail.

```bash
echo "Building and testing $TASK_IDENTIFIER"
cmake --build build -j 4
cmake --build build --target format-check
cd build && ctest --output-on-failure -j 4
```

## before_review

Executes when task enters review (blocking, 60s timeout).
This project is trunk-based: work lands on main directly and no pull request is
opened, so this hook only pushes what after_doing just verified.

```bash
echo "Publishing $TASK_IDENTIFIER to main"
git push origin main
```

## after_review

Executes after review approval (blocking, 60s timeout).
If this fails, mark_reviewed should fail.

```bash
echo "Task $TASK_IDENTIFIER approved"
```
